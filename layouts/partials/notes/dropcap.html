{{- /* Engraved drop cap for the first letter of a note, set after Bringhurst: - the letter spans three lines, cap-top of line 1 to the baseline of line 3 - the text is mortised against the letter line by line (shape-outside; see assets/css/dropcaps.css, generated by scripts/build-dropcaps.py) - when the initial begins a longer word ("In my...") the gap is tight; when it is a word on its own ("I feel...") a full word space follows - the rest of the first word and the next two words are set in small caps (the "run-in") Input: the rendered page content (string). Output: the same content with the opening paragraph rewritten. The real letter stays in the DOM (visually hidden), so copy/paste, search and screen readers still read the word whole. Applies only when the content *starts* with a plain paragraph whose first character is a letter followed by another letter or whitespace (contractions like "I've" are skipped), the paragraph is at least dropcapMinChars long (default 200, about three lines), and a letter exists in data/dropcaps.json. J uses the I plate and U the V plate, as the classical alphabet has neither. Otherwise the content is returned untouched. */ -}} {{- /* Input is either the content string (notes: min length from params.notes.dropcapMinChars, default 200) or a dict {content, minChars} (posts' hero lead passes its own, default 135). */ -}} {{- $content := . -}} {{- $minChars := int (default 200 (site.Params.notes).dropcapMinChars) -}} {{- if reflect.IsMap . -}} {{- $content = .content -}} {{- $minChars = int .minChars -}} {{- end -}} {{- $firstP := "" -}} {{- with findRE `(?s)^\s*]*)?>.*?

` $content 1 }}{{ $firstP = index . 0 }}{{ end -}} {{- $len := strings.RuneCount ($firstP | plainify | htmlUnescape | chomp) -}} {{- if ge $len $minChars -}} {{- with findRESubmatch `(?s)^\s*(]*)?>)\s*([A-Za-z])((?:[A-Za-z]|\s)[^<\s]*(?:\s+[^<\s]+){0,2})` $content 1 -}} {{- $m := index . 0 -}} {{- $tag := index $m 1 -}} {{- $ch := index $m 2 -}} {{- $rest := index $m 3 -}} {{- $key := upper $ch -}} {{- if eq $key "J" }}{{ $key = "I" }}{{ end -}} {{- if eq $key "U" }}{{ $key = "V" }}{{ end -}} {{- if index (default dict site.Data.dropcaps) $key -}} {{- /* initial is itself a word when whitespace follows it */ -}} {{- $isWord := findRE `^\s` $rest -}} {{- $cls := printf "dc-para dc-%s" $key -}} {{- if $isWord }}{{ $cls = printf "%s dc-word" $cls }}{{ end -}} {{- if findRE `class="` $tag -}} {{- $tag = replaceRE `class="` (printf `class="%s ` $cls) $tag 1 -}} {{- else -}} {{- $tag = replaceRE `^` -}} {{- $out := "" -}} {{- if $isWord -}} {{- $sp := index (findRE `^\s+` $rest) 0 -}} {{- $run := strings.TrimLeft " \t\r\n" $rest -}} {{- $out = printf `%s%s%s%s` $tag $glyph $ch $sp -}} {{- if $run }}{{ $out = printf `%s%s` $out $run }}{{ end -}} {{- else -}} {{- $out = printf `%s%s%s%s` $tag $glyph $ch $rest -}} {{- end -}} {{- $content = replace $content (index $m 0) $out 1 -}} {{- end -}} {{- end -}} {{- end -}} {{- return ($content | safeHTML) -}}
